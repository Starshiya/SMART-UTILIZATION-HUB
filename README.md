⭐ StarShiya Hub

«Your Everyday Digital Toolkit»

StarShiya Hub is a modern, responsive web-based utility hub that brings essential everyday tools together in one place.

The project starts with an animated loading experience and a branded splash screen before opening the main dashboard, where users can access different utilities such as Calculator, Notes, Clock, Camera, and Gallery.

▶️ How to Run

Option 1 — Open Locally

Download or clone the project and open:

index.html

in a modern web browser.

Option 2 — Use a Code Editor

Open the project folder in an editor such as VS Code and run "index.html" using a local development server.

📱 Browser Permissions

The Camera feature requires permission from the browser.

When prompted:

Allow StarShiya Hub to access your camera

select Allow.

Camera functionality works best when the website is served through a secure context such as HTTPS or a local development server.

💾 Data Storage

StarShiya Hub currently uses browser LocalStorage.

Notes and gallery information are stored locally in the user's browser.

No external database is currently required.

«Clearing browser storage may remove saved notes and gallery data.»

🌟 Project Goal

The goal of StarShiya Hub is to create a simple and attractive all-in-one digital utility platform where commonly used tools can be accessed quickly from a single interface.

Instead of opening multiple websites or applications, users can access their everyday utilities from one place.
